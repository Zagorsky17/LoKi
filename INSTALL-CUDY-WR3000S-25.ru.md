# Установка беты LoKi на Cudy WR3000S с OpenWrt 25.12

Инструкция предназначена для уже установленного OpenWrt 25.12 с пакетным менеджером APK и архитектурой `aarch64_cortex-a53`. LoKi устанавливается как приложение; прошивка роутера не заменяется. Первая установка на реальном WR3000S ещё не проверена. Выполняйте её по кабелю, сохранив доступ к SSH и резервную копию настроек OpenWrt.

## Установка одной командой

Подключитесь к роутеру по SSH от `root` и выполните:

```sh
(set -o pipefail; wget -O - https://raw.githubusercontent.com/Zagorsky17/LoKi/main/install-beta.sh | sh)
```

Загрузчик выбирает комплект для OpenWrt 24.10 или 25.12 на `aarch64_cortex-a53`, проверяет размер и SHA256, распаковывает его в закрытом временном каталоге и выполняет отдельный preflight. Только после успешной проверки запускается существующий установщик компонентов. На неподдерживаемой системе, при нехватке памяти, ошибке сети или конфликте установка останавливается с причиной. Общие зависимости и настройки сети автоматически не меняются.

Начальный бюджет вычисляется по размерам конкретного комплекта и резервам preflight: для этой беты это около 97 МиБ `MemAvailable` и свободного `/tmp`. Если LoKi уже установлен, сначала нажмите Stop: команда использует тот же механизм проверки и сохранения собственной конфигурации. После успеха временные файлы удаляются; при ошибке транзакции комплект остаётся закрытым и выводится команда восстановления.

Откройте LoKi в LuCI, настройте подключения и DNS, затем нажмите Start. Команда выполняет загрузку и установку; она не включает маршрутизацию автоматически. Исходный загрузчик получен из собственного репозитория по HTTPS, комплект закреплён SHA256; независимой подписи нет.

Разделы ниже описывают запасной ручной способ, диагностику и восстановление.

## 1. Проверьте устройство и свободную память

Подключитесь к роутеру по своему обычному SSH-адресу и выполните:

```sh
ubus call system board
cat /etc/openwrt_release
command -v apk
grep MemAvailable /proc/meminfo
df -Pk / /tmp
```

Для WR3000S v1 официальный профиль OpenWrt имеет имя `cudy_wr3000s-v1`, платформу `mediatek/filogic` и архитектуру пакетов `aarch64_cortex-a53`. Сверьте фактические значения: при другой модели, архитектуре или ветке OpenWrt этот комплект не устанавливайте. [Профили OpenWrt 25.12.6](https://downloads.openwrt.org/releases/25.12.6/targets/mediatek/filogic/profiles.json).

Комплект занимает около 25,5 МБ в архиве и 47 МБ после распаковки. При удалении скачанного архива после проверки распакованных файлов начальная оценка составляет около 97 МиБ свободного `/tmp` и `MemAvailable`. Архив и резерв preflight требуются на разных этапах, поэтому их размеры не складываются одновременно. Это предварительный бюджет; установщик отдельно проверяет точные потребности пакетов, резервной копии и свободного места в `/`. При недостатке ресурсов он откажет. Swap не заменяет доступную RAM.

Миграция с Forkop, Podkop и других приложений не поддерживается. Предварительная проверка выявляет мешающие службы, DNS, firewall, маршруты и остатки пакетов. Она не удаляет чужие данные и не исправляет конфликты автоматически.

## 2. Получите комплект на компьютере

В [бета-релизе 2.0.0](https://github.com/Zagorsky17/LoKi/releases/tag/2.0.0) скачайте файл:

`loki-2.0.0-r10-openwrt-25.12-aarch64_cortex-a53-candidate.tar.gz`

SHA256 архива:

```text
c9f1163d5bb9cb7c286802b63ff3660e7c8422852227a5687dea5122980741c9
```

На macOS проверьте его командой `shasum -a 256 ИМЯ_АРХИВА`, на Linux — `sha256sum ИМЯ_АРХИВА`. Результат должен точно совпасть. HTTPS и SHA256 защищают передачу и проверяют согласованность файлов; отдельной цифровой подписи нет, поэтому компрометация самого репозитория остаётся ограничением доверия беты.

Вместо `АДРЕС_РОУТЕРА` ниже подставьте адрес вашего SSH-подключения. Не копируйте на роутер исходники, оба формата пакетов или весь релиз. На компьютере выполните:

```sh
ssh root@АДРЕС_РОУТЕРА 'umask 077; mkdir -m 700 /tmp/loki-beta-upload'
scp -O loki-2.0.0-r10-openwrt-25.12-aarch64_cortex-a53-candidate.tar.gz root@АДРЕС_РОУТЕРА:/tmp/loki-beta-upload/
```

Первую команду выполните отдельно: при ошибке остановитесь и разберите причину. `scp -O` использует SCP без SFTP, которого может не быть в OpenWrt. Существующий SSH-ключ используйте через свой обычный профиль; проверку ключа сервера не отключайте.

## 3. Распакуйте и выполните preflight

Следующие команды выполняются от `root` на роутере. Каждую группу запускайте только после успеха предыдущей.

```sh
ARCHIVE=/tmp/loki-beta-upload/loki-2.0.0-r10-openwrt-25.12-aarch64_cortex-a53-candidate.tar.gz
sha256sum "$ARCHIVE"
```

Снова сравните результат с суммой выше. Затем создайте новый закрытый каталог и распакуйте архив:

```sh
umask 077
mkdir -m 700 /tmp/loki-beta && tar -xzf "$ARCHIVE" -C /tmp/loki-beta
```

При ошибке `mkdir` не переиспользуйте существующий каталог. Архив уже содержит закрытые права доступа; распаковка от `root` обеспечивает требуемого владельца файлов.

```sh
KIT=/tmp/loki-beta/openwrt-25.12-aarch64_cortex-a53
MANIFEST_SHA256=60330a1e5a35778af13f4d50fa6944852bcbbd781fffaf0f157ecfeb929de48f
cd "$KIT" && sha256sum -c SHA256SUMS
```

Все файлы должны пройти проверку. После успеха удалите только перенесённый архив, чтобы освободить память до preflight; исходный архив на компьютере сохраните:

```sh
rm -f "$ARCHIVE"
```

Затем запустите:

```sh
sh "$KIT/preflight.sh" --manifest-sha256 "$MANIFEST_SHA256" > /tmp/loki-beta-preflight.json
STATUS=$?
cat /tmp/loki-beta-preflight.json
printf 'Exit: %s\n' "$STATUS"
```

Продолжать можно только при `Exit: 0`, `result: "checked"`, `complete: true` и `install_allowed: true` одновременно. `conflict`, `incomplete`, таймаут и отсутствие результата запрещают установку. Сохраните JSON для разбора; не обходите отказ ручным `apk add --allow-untrusted` и не удаляйте чужие пакеты наугад. На минимальной прошивке могут отсутствовать требуемые модули или работающий HTTPS-provider; установщик не загружает общие зависимости и не обновляет OpenWrt автоматически.

## 4. Установите и запустите LoKi

После успешной проверки:

```sh
sh "$KIT/component-update.sh" install "$KIT" "$MANIFEST_SHA256"
```

Дождитесь завершения и `success: true`. Установщик повторяет preflight перед изменениями и работает только с собственными компонентами LoKi. Не прерывайте питание и не запускайте параллельно пакетный менеджер.

Обновите страницу LuCI и откройте LoKi. Добавьте собственную ссылку подключения или подписку, настройте секции и DNS, сохраните настройки и явно нажмите Start. По умолчанию шифрование DNS выключено; для шифрования выберите DoH или DoT и задайте соответствующий сервер. Автоматического перехода между протоколами нет. Если интерфейс LoKi не появился, заново войдите в LuCI и проверьте журналы; не перезапускайте сеть наугад.

Проверьте подключение, Start/Apply/Stop, Monitoring и Logs. После Start снимите показатели:

```sh
for pid in $(pidof loki-core); do printf 'PID %s\n' "$pid"; grep VmRSS "/proc/$pid/status"; done
grep MemAvailable /proc/meminfo
df -Pk / /tmp
```

Сохраните результат preflight, версию прошивки, параметры нагрузки и измерения памяти. Содержимое подписок, токены, пароли и полные конфигурации перед публикацией логов удаляйте. Программные проверки Linux не подтверждают реальные rpcd/procd, пакетные hooks, нагрузку ARM64 или восстановление после потери питания.

## 5. Обновление, удаление и восстановление

Перед обновлением или удалением нажмите Stop в LoKi. Для обновления нужен новый полный комплект с его собственной суммой manifest: повторите проверки для него, затем выполните `sh "$KIT/component-update.sh" update "$KIT" "$MANIFEST_SHA256"`. Повторное использование суммы от другой версии запрещено.

Для удаления текущей версии используйте соответствующий проверенный комплект:

```sh
sh "$KIT/uninstall.sh" "$KIT" "$MANIFEST_SHA256"
```

Если транзакция оборвалась, сохраните её сообщение и журнал. Для восстановления состояния собственной транзакции выполните:

```sh
sh "$KIT/component-update.sh" recover
```

Если восстановление отказывает, передайте причину для разбора. Не удаляйте lock/journal и не переустанавливайте пакеты вручную поверх незавершённой операции.

Каталоги `/tmp/loki-beta`, `/tmp/loki-beta-upload` и результат preflight исчезнут после перезагрузки. Сохраните исходный архив на компьютере; перед удалением временных файлов убедитесь, что установка или восстановление завершены и каталог больше не используется.
