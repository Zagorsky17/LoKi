# LoKi

Русский · [English](README.md)

> **Приложение находится в стадии активной разработки.** Изменения могут попадать в `main` до полного цикла проверок; проверки и исправления продолжаются после публикации. Стабильность на OpenWrt и поведение при отказах DNS/TLS ещё не подтверждены лабораторными испытаниями.

Маршрутизация трафика OpenWrt по правилам с помощью sing-box. LoKi — независимо развивающийся форк [Forkop](https://github.com/ushan0v/forkop) на базе версии 2.0.0, коммит `9544f3de09c62c935e1147147136234594d04f02`.

Репозиторий проекта — [Zagorsky17/LoKi](https://github.com/Zagorsky17/LoKi). Ошибки и предложения принимаются в [LoKi Issues](https://github.com/Zagorsky17/LoKi/issues).

## Состояние разработки

На 31.10.2026 в репозитории нет релиза LoKi. Установщик и проверки обновлений приложения используют **`Zagorsky17/LoKi`**: пакеты приложения загружаются из этого репозитория, без возврата к релизам Forkop. Для установки нужен релиз LoKi с файлами пакетов; одной публикации исходников в `main` недостаточно. Ядро пока загружается из `ushan0v/sing-box-forkop` до завершения работ по совместимости. Установка и обновление на роутере ещё не проверены.

В исходниках пока используются технические имена `forkop`, `luci-app-forkop` и `/etc/config/forkop`. Их согласованная замена запланирована вместе с переносом конфигурации.

## Планируемые возможности

В LoKi останутся ссылки подключений, подписки, секции маршрутизации, DNS, мониторинг и диагностика. VPN-сервер, туннели и миграции с Forkop 1.0.x запланированы к удалению; в унаследованном коде они ещё присутствуют.

Целевые версии — OpenWrt 24.10 и 25.12. Совместимость со штатными пакетами sing-box и новыми версиями ядра предстоит реализовать и проверить. Унаследованный код пока требует `sing-box-forkop`.

Внешними зависимостями остаются встроенные списки [forkop-lists](https://github.com/ushan0v/forkop-lists) и диагностические домены `ip.podkop.fyi` и `fakeip.podkop.fyi`.

## Настройки DNS в разрабатываемой версии

В разрабатываемом интерфейсе режим шифрования задаётся явно для всего основного списка DNS: «Выключено (UDP)» либо «Включено» с обязательным выбором DoH или DoT. Адреса должны соответствовать выбору: `https://dns.example/dns-query` для DoH, `tls://dns.example` для DoT, IP-адрес для UDP. `dns.example` — учебное имя; укажите адрес своего резолвера. Смена режима не переписывает адреса и не переключает протокол при отказе сервера.

Bootstrap использует UDP по IP. Имена исходящих соединений без собственного резолвера разрешаются через bootstrap; явные настройки JSON и интерфейсов сохраняются. Новая конфигурация сохраняет прежний режим UDP. Для старых настроек без поля шифрования протоколы в адресах продолжают действовать, а при редактировании интерфейс требует явного выбора режима. Эти изменения ещё требуют проверки на лабораторном OpenWrt.

## Документация и проверки

Публичная документация проекта ведётся в этом README и [README.md](README.md). Унаследованный сайт `docs/` описывает Forkop и запланирован к удалению.

Тесты и сборки пакетов выполняются на выделенном Linux-сервере разработки. Отказы DNS, перехват трафика и установку перед релизом дополнительно проверяют на лабораторном OpenWrt. Для тестов безопасности используются синтетические реквизиты и локальные тестовые сервисы.
