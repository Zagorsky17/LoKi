# Установка LoKi на OpenWrt

LoKi устанавливается как приложение на OpenWrt 24.10 с `opkg` и OpenWrt 25.12 с `apk`. Производитель и модель устройства не участвуют в выборе пакетов: установщик определяет пакетный менеджер и архитектуру самой прошивки. Для этой архитектуры в релизе должна быть сборка `loki-core`.

## Установка

Подключитесь к OpenWrt по SSH от `root` и выполните:

```sh
(set -o pipefail; wget -O - https://raw.githubusercontent.com/Zagorsky17/LoKi/main/install-loki.sh | sh)
```

Основная ссылка постоянная. Загрузчик полностью скачивает `install.sh` во временный файл с закрытыми правами и запускает его после успешной загрузки. Этот же установщик используется страницей компонентов в LuCI.

Установщик получает сведения о последнем опубликованном релизе, выбирает пакеты приложения и подходящее ядро, проверяет SHA256, затем выполняет пробную операцию штатного пакетного менеджера. Необходимые зависимости устанавливаются из настроенных фидов OpenWrt. Прошивка не перепрошивается. Конфигурации других приложений не импортируются.

Оценка свободного места относится к файловой системе, в которой устанавливаются пакеты. Потребность в RAM и `/tmp` вычисляется по скачиваемым пакетам и операциям установки; фиксированного порога 160 МиБ и обязательного офлайн-кита больше нет.

Если работает другое приложение `sing-box`, сначала остановите его и повторите установку. Скрипт не удаляет его пакеты или настройки. Если пакетный менеджер не может получить зависимости, сообщает о несовместимой версии ядра Linux или о конфликте файлов, сохраните конкретную ошибку: обходить её параметрами принудительной установки не следует.

После сообщения об успешной установке заново откройте LuCI и страницу LoKi. Добавьте подключения, настройте секции и DNS, сохраните настройки и нажмите Start. Первичная установка не применяет пустую конфигурацию маршрутизации. Шифрование DNS настраивается отдельно: выберите DoH или DoT и задайте соответствующий сервер.

## Обновление и удаление

Для обновления повторите основную команду или используйте страницу компонентов LoKi в LuCI. Установщик сохраняет собственную конфигурацию и восстанавливает прежнее состояние службы: остановленная служба остаётся остановленной; работавшая запускается после обновления.

Для удаления скачайте тот же основной скрипт и запустите его с `--uninstall`:

```sh
script=$(mktemp /tmp/loki-uninstall.XXXXXX) &&
wget -T 30 -O "$script" https://raw.githubusercontent.com/Zagorsky17/LoKi/main/install.sh &&
sh "$script" --uninstall
rm -f "$script"
```

Обычное удаление сохраняет настройки LoKi. Параметр `--purge` дополнительно удаляет их; используйте его только при намеренном удалении настроек.

## Если операция остановилась

Сообщение установщика указывает этап и путь к его журналу. Сохраните вывод терминала и этот журнал. Укажите версию OpenWrt, архитектуру и используемый пакетный менеджер:

```sh
cat /etc/openwrt_release
grep MemAvailable /proc/meminfo
df -Pk / /tmp
```

В журнале могут быть временные подписанные ссылки загрузки. Перед публикацией уберите из него собственные токены, пароли и содержимое подключений.

SHA256 проверяет соответствие файлов опубликованным суммам. Источником доверия остаются собственный репозиторий LoKi и HTTPS; независимой цифровой подписи нет. Стендовые проверки Linux не заменяют проверку реальных пакетных hooks, rpcd/procd и нагрузки конкретного OpenWrt.
