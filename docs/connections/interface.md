# Сетевой интерфейс

Секция может направлять трафик через уже существующий интерфейс OpenWrt: второй WAN, LTE-модем или другое настроенное устройство. LoKi привязывает исходящее соединение к выбранному устройству; пакеты, ключи, адреса и жизненный цикл внешних VPN-приложений он не настраивает.

В секции с действием **Подключение** выберите **Сетевой интерфейс** и устройство. Устройство должно существовать и иметь рабочий выход до применения настроек LoKi. Несколько интерфейсов можно объединить в [Fallback](/connections/fallback), например основной WAN и LTE. Отказ устройства проверяйте по состоянию OpenWrt и проверке доступности соответствующего выхода.

Встроенные WireGuard, AmneziaWG, WARP, Tailscale, OpenVPN, OpenConnect и JSON endpoint удалены. Сохранение выхода через существующий интерфейс не добавляет их управление в LoKi.

## Резолвер доменов

**Резолвер доменов** задаёт DNS для исходящих соединений данного интерфейса вместо общего резолвера. Это позволяет обращаться к внутренним именам сети, доступной через устройство.

Серверы задаются в [форматах DNS](/dns/#форматы); порядок нескольких серверов определяется [DNS Fallback](/dns/#dns-fallback). Запросы резолвера идут через сам интерфейс. **DNS через секцию** позволяет выбрать другую секцию для этих запросов; её подключение должно оставаться доступным без циклической зависимости от настраиваемого интерфейса.
