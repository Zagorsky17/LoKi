# JSON outbound

Подключение, описанное объектом outbound sing-box. Пригодится, для параметров исходящего подключения, которых нет в редакторе ссылок. Поле `tag` обязательно, оно становится именем сервера.

WireGuard, AmneziaWG, WARP, Tailscale, OpenVPN, OpenConnect и серверный OpenVPN отклоняются формой и бэкендом: ручной JSON не возвращает удалённые VPN-функции. Остальные параметры объекта дополнительно проверяет установленное ядро через `sing-box check` до применения настроек.

```json
{
  "type": "vless",
  "tag": "my-server",
  "server": "203.0.113.10",
  "server_port": 443,
  "uuid": "00000000-0000-4000-8000-000000000000",
  "flow": "xtls-rprx-vision",
  "tls": {
    "enabled": true,
    "server_name": "www.microsoft.com",
    "utls": { "enabled": true, "fingerprint": "chrome" },
    "reality": {
      "enabled": true,
      "public_key": "…",
      "short_id": "0123abcd"
    }
  }
}
```

## Выход без VPN

Так в секцию добавляется и прямой выход через провайдера:

```json
{
  "type": "direct",
  "tag": "Напрямую"
}
```

На дашборде он появится среди серверов секции, и секцию можно будет переключить на прямой выход одним щелчком. URLTest считает его обычным сервером и может выбрать как самый быстрый, поэтому исключите его в фильтре URLTest.
